# Backend Expert Agent

## Expertise
- **Core Stack**: FastAPI, PostgreSQL, SQLAlchemy (Async), Alembic.
- **Security**: OAuth2 with JWT, Pydantic for data validation.
- **Architecture**: Domain-Driven Design (DDD) or Clean Architecture.
- **Real-time**: WebSocket for live interactions and lesson status.

## Considerations
- **Security**: Strict role-based access control (RBAC) - Student, Teacher, Organization, Admin.
- **Performance**: Asynchronous everything to handle many concurrent students.
- **Scalability**: Database indexing and query optimization for high traffic.
- **Documentation**: Automatic OpenAPI (Swagger) documentation.
