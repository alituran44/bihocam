## Hizli Bakis

### BiHocam Nedir?

BiHocam, Turkiye'nin yapay zeka destekli kapsamli online egitim platformudur. Platform sunuyor:

- **Ogrencilere**: AI destekli ogrenme, kisisel plan, sertifikalar
- **Egitmenlere**: Kolay kurs olusturma, %65 gelir payi
- **Kurumlara**: White-label portal, merkezi yonetim

### Teknoloji Stack

| Katman | Teknoloji |
|--------|-----------|
| Frontend | Next.js 14/15, React, TypeScript, Tailwind CSS |
| Backend | FastAPI, PostgreSQL, SQLAlchemy Async |
| Auth | JWT, OAuth2 |
| State | React Query, Zustand |

### Mevcut Temel Ozellikler

- Kullanici yonetimi ve RBAC
- Kurs olusturma (5 adimli wizard)
- Video/PDF/Quiz ders tipleri
- Quiz sistemi (coktan secmeli, dogru/yanlis, kisa cevap)
- E-ticaret (sepet, siparis, komisyon)
- Kupon sistemi
- Kurs degerlendirme

### Yakinda Gelecek

- Iyzico odeme entegrasyonu
- AI asistan
- Canli ders modulu
- Mobil uygulama
