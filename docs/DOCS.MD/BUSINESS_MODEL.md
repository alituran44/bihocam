# BiHocam - Is Modeli ve Gelir Stratejisi

## Yonetici Ozeti

BiHocam, Turkiye'nin egitim teknolojisi pazarindaki boslugu doldurmak icin tasarlanmis, cok tarafli bir egitim platformudur. Platform, ogrencilere, egitmenlere ve kurumlara hizmet vererek cesitli gelir akislari olusturur.

## 6. Birim Ekonomi

### 6.1 Ogrenci Edinme Maliyeti (CAC)

```
CAC = Pazarlama Harcamasi / Yeni Musteriler

Hedef CAC:
- Organik: 0 TL
- Referans: 10 TL
- Paid Ads: 30-50 TL
- Ortalama: 20 TL
```

### 6.2 Yasam Boyu Deger (LTV)

```
LTV = Ortalama Satis x Satın Alma Sıklığı x Muster Omru

Ortalama Kurs: 150 TL
Platform Geliri: 52.5 TL (%35)
Yillik Satin Alma: 3 kurs
Musteri Omru: 2 yil

LTV = 52.5 x 3 x 2 = 315 TL
```

### 6.3 LTV/CAC Orani

```
LTV/CAC = 315 / 20 = 15.75x

Hedef: >3x (Saglikli)
Gercek: 15.75x (Mukemmel)
```

### 6.4 Abonelik Metrikleri (Planlanan)

| Metrik | Hedef |
|--------|-------|
| MRR (Monthly Recurring Revenue) | 500K TL |
| Churn Rate | <%5 |
| Expansion Revenue | >%10 |
| Net Revenue Retention | >%100 |
